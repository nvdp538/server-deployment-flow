## 第二步：装环境，能一键就别手动

要不要手动装，取决于你的网站类型。纯 HTML/CSS 静态页面只需要一个 Web 服务器软件（Nginx 或 Apache）；WordPress 需要 PHP + MySQL；Node.js 项目需要对应的运行时。轻量应用服务器的应用镜像就是把这些组合预装好，开机即用；CVM 或想精确控制版本的情况，就 SSH 登录后手动装，或者装个宝塔面板用图形界面管理站点、数据库和证书。

网上很多教程教你编译安装 JDK、Tomcat 再改配置文件，那是特定年代的路径。现在大多数建站场景用镜像或面板十分钟能完成同样的效果。👉 [用预装应用镜像的轻量服务器跳过手动配置](https://bit.ly/yunhuodong)

## 第三步：把网站文件传上去

用 FileZilla、Xftp 这类工具通过 SFTP 连接服务器，输入公网 IP、用户名和密码，把本地网站目录整个拖过去。装了面板的话，直接在面板的文件管理器里上传压缩包再在线解压，比一个个文件传快得多。

两个容易出错的地方：一是文件要放进 Web 服务器配置的站点根目录，不是随便一个文件夹，路径取决于你用的环境，面板通常会在站点设置里直接显示；二是首页文件名要符合默认首页规则，`index.html` 或 `index.php` 这类命名才能被自动识别，换成 `home.html` 就得改配置。

## 第四步：放行 80 和 443 端口

服务器在运行、文件也传了，外网却打不开，十有八九是端口没放行。轻量应用服务器在控制台的防火墙页面添加规则，CVM 在安全组里配置入站规则，放行 80（HTTP）和 443（HTTPS）。SSH 用的 22 端口一般默认已开，如果连不上可以先查这一项。

放行之后，在浏览器地址栏输入服务器的公网 IP，能看到你的页面，说明部署的技术部分已经通了。这时候还没有域名，用 IP 访问完全正常。

## 第五步：域名解析，以及绕不开的备案

域名可以在腾讯云或其他注册商购买，买完先做实名认证，然后在 DNS 解析里添加一条 A 记录，把域名指向服务器的公网 IP。解析生效通常几分钟到几小时。

关键限制在这里：**服务器在中国大陆地域，域名必须完成 ICP 备案才能正常访问**，没备案的域名解析过去也会被拦截。备案本身不收费，花的是时间——管局审核时限在 20 个工作日以内，实际按周计算，别指望当天上线。备案期间网站不会闲着，用 IP 地址先把功能调通、内容传好，备案一通过换上域名就能对外。如果服务器选在香港或海外地域，不需要备案，但访问速度和合规要求是另一笔账，自己权衡。

## 带宽选多大才不会打开慢

带宽单位是 bit，下载速度单位是 Byte，1 Byte = 8 bit，所以 1M 带宽的下载峰值约 128KB/s，3M 约 384KB/s。打开浏览器开发者工具的 Network 面板，看自己页面「已传输」的资源大小，用这个数字除以带宽速度，就能粗算出首屏加载时间。一个 1MB 左右的页面挂在 1M 带宽上，理论上要 8 秒才能拉完；同样页面放到 3M 带宽，三秒出头。图片多、没做压缩的站，实际体验还要更差。轻量应用服务器的带宽随套餐固定，CVM 可以自选带宽计费方式，选之前先算一遍这笔账。

## 常见问题

**没有域名能部署网站吗？** 能。用公网 IP 直接访问，适合测试和内部使用，正式对外还是建议配域名。

**部署一个网站要多久？** 买服务器、配环境、传文件、开端口这几步，顺利的话半天内完成；备案另算，按周计。

**网站打不开该从哪里查？** 按顺序排查：服务器是否运行中 → 80 端口是否放行 → Nginx 或 Apache 服务是否启动 → 域名解析是否生效。四步里总有一环是断的。

**纯静态网站一定要买服务器吗？** 不一定。对象存储也能托管静态站点，成本结构不同，但自定义配置、伪静态、后端接口这些需求它处理不了。图省事、以后可能加动态功能，还是服务器更省心。

**轻量应用服务器和 CVM 之后能改配置吗？** 都支持在控制台调整，轻量是更换套餐档位，CVM 是变配实例规格，具体规则和费用以控制台说明为准。
